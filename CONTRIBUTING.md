# Contributing to Meta-Loop iOS

Thank you for your interest in contributing! This document provides guidelines for contributions.

## Ways to Contribute

1. **Report bugs** - File issues for problems you encounter
2. **Suggest improvements** - Open discussions for methodology enhancements
3. **Submit examples** - Share real-world usage patterns
4. **Improve documentation** - Clarify or expand the guides

## Pull Request Process

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/improvement`)
3. Make your changes
4. Test with a real iOS project
5. Submit a pull request with a clear description

## Documentation Guidelines

Since this is a documentation-heavy project:

- Keep examples generic (not tied to specific apps)
- Use clear, actionable language
- Include both "what" and "why"
- Test commands in Claude Code before submitting

## Command Guidelines

When modifying commands (`commands/*.md`):

1. Preserve the four-phase structure (Plan → Write → Review → Complete)
2. Keep platform-agnostic where possible
3. Reference documentation rather than duplicating it
4. Test the full workflow end-to-end

## Code of Conduct

- Be respectful and constructive
- Focus on the methodology, not specific tools
- Welcome newcomers to AI-assisted development

## Questions?

Open an issue or start a discussion. We're happy to help!
